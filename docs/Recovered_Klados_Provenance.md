# Recovered Klados export provenance

The complete local dataset folders and neighboring EEG work were searched for the original MATLAB files, exporter scripts, electrode lists and participant mappings. The existing four NPY files and archived loader/window metadata did not contain them. The publisher originals were recovered from [Mendeley version 4](https://data.mendeley.com/datasets/wb6yvr725d/4), downloaded and verified against all four published SHA256 hashes on Kaggle.

Kaggle source-check version 2, Git `88615e8621766cb4e8e3e021afa0527d8de86869`, passed 20 numerical contract tests in 7.67 seconds. It proved exact full-matrix matches after float32 conversion for all 53 records in each of the four local exports. The operation is an explicit start crop: samples `[0:5401]`, amplitude scale 1, and no electrode reordering, filtering or inferred time offset. Every NPY record resolves to the same unique publisher recording in clean EEG, contaminated EEG, HEOG and VEOG.

Publisher recording **45** is absent from all four local exports. The original MATLAB variables are `sim45_resampled`, `sim45_con`, `heog_45` and `veog_45`. The publisher source contains 54 variable-length recordings; recording 45 has 8,401 samples. The reason the previous exporter omitted it is unknown. Do not invent that reason or silently append it to an already evaluated split. The 53-record engineering comparison remains fixed; a future 54-record analysis needs its own declared split and baseline reruns.

The results directory retains the four complete original MATLAB files, the download/hash ledger, structural metadata, all record-level matches, unused-original lists and four-way alignment. `data_provenance/klados_verified_export_mapping.json` is a compact metadata copy of the verified correspondence. These are provenance findings, not cleaning-quality metrics.

The [original article](https://doi.org/10.1016/j.dib.2016.06.032), read through the authoritative NCBI BioC full-text endpoint, specifies 200 Hz, EEG preprocessing at 0.5–40 Hz with a 50-Hz notch, and EOG filtering at 0.5–5 Hz. It describes left/right mastoid references for lateral EEG and the mastoid average for midline electrodes. The article lists FP1, FP2, F3, F4, C3, C4, P3, P4, O1, O2, F7, F8, T3, T4, T5, T6, Fz, Cz, Pz. This establishes that the acquisition includes frontal and posterior electrodes. However, the text does not explicitly declare that list to be the MATLAB row order. The four source files contain signal variables alone, with no named channel/participant fields. Treat the listed order as a candidate, not a verified row map.

The article describes 27 people and 54 recordings. It does not identify which `simN` belongs to which person. Neither consecutive pairs nor pairs separated by 27 are automatically valid participant groups. Subject-independent Klados claims therefore remain blocked. Named OSF EEG electrodes and globally unique participant identifiers support the regional and participant-isolated OSF analyses.

The amplitude scale between source and NPY is verified as unchanged. The physical unit is still unspecified in the recovered files/article. The current experiment deliberately applies its declared filter to input and paired target; the source was already filtered, so this is a second filtering pass and should be disclosed in matched comparisons. It cannot recreate frequencies removed by the original acquisition preprocessing.
