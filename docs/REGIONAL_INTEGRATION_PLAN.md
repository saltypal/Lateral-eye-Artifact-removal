# Exploratory regional integration — 12 October 2026

Goal: measure whether composing the fixed frontal corrections with the existing
source-excluded posterior recipes improves whole-cap reconstruction. Native
preservation remains failed; this stage cannot qualify a teacher or deployment.

Inputs are immutable corpus/2, readiness/1, frontal monotonic/1 and posterior
full/1 artifacts. Their complete manifests are explicitly pinned in the new
schema4 configuration, with existing preprocessing/source split contracts.
No AutoVMD, posterior VMD, new neural training or correction parameter search.

The four frontal variants are calibrated raw and fixed K3/2000 mode gain,
each ungated and monotonic temporal-event restricted. Reuse their saved
predictions after exact input/target/channel and artifact checksum validation.
Apply all existing fold-selected posterior method/support recipes rather than
selecting from their best-candidate search table. Calibration refitting uses
original EEG only; reference association excludes trial joins. Verify re-applied
posterior metrics against the archived OOF values before composing.

Compare pass-through plus direct/ICA/MWF with posterior/common/signed/raw/full
support as inherited. Hyperparameters differ between fold-selected support arms;
this is not a matched-parameter causal proof of context benefit. Estimated frontal
artifact communication is a later arm and is not implemented in this first run.

Metrics: per-channel MSE/RRMSE/Pearson/output SNR/improvement, equal recipient
weighting, separate conditions/input levels, full/frontal/posterior scopes;
pooled-energy SNR separately labelled. Full correlation gate compares calibrated
raw frontal plus fold-selected direct posterior. Report all failures/pass-through.
Shared/unknown channels remain original. Disjoint masks and single subtraction
are numerical contracts. No dB addition.

First run is a focused pilot (one recipient per frozen fold, clean plus nominal
0dB ocular conditions). Full320-example execution follows only after software,
parent and prediction-parity checks pass. All tests and metrics run on Kaggle.
Results retain predictions, source SHA, parent manifests, progress, gates and
diagnostic plots. Native safety and final model qualification remain separate.
