# Validation-constrained neural search

This extension follows the development failure of the first six-record prototype. It keeps the original 70/15/15 record split, shared model, VMD preference and same preprocessing. The core modules remain the Git authority. All computation runs on Kaggle.

The first model modified paired clean EEG by about 12–13% in two inspected smoke records. The initial identity loss divided clean reconstruction by contaminated-window scale. That reduces its weight when contaminated amplitude is large. This version uses the clean window's own standard deviation, starts residual heads at zero, and trains the intervention gate against legitimate paired power burden. Positive artifact/clean power is greater than -10 dB; clean is at most -20 dB. Intermediate burden does not supervise the binary gate. These labels describe ocular burden; they do not distinguish a blink from a vertical saccade.

Training uses all 37 training records, eight validation records and eight held-out records. Each record supplies three nonoverlapping 1,024-sample windows starting at 2,000, 3,024 and 4,048. The first 10 seconds remain excluded from scoring. Windows never cross source-record boundaries. Electrode and subject mappings remain unverified; this is record-held-out validation. Records 5 and 14 were already inspected in the earlier smoke run and must be labeled separately. Six remaining test records have not supplied design evidence.

The eight training configurations are identity weights {0.25,1,4,16} crossed with learning rates {0.001,0.0003}, seed 42, 60 epochs, AdamW weight decay 0.0001, batch eight, gate weight 0.05 and trusted-teacher distillation weight 0.10. Fifteen-percent channel masking retains at least one electrode. Frozen VMD/ICA teachers cover only the first six training records and the first scoring window; the remaining examples use paired supervision. Teacher acceptance retains the earlier loose engineering guard and is not final preservation certification.

Each epoch evaluates correction strengths {0,0.1,0.25,0.5,1} on validation records. Select minimum record-macro RMSE among settings whose worst-record mean clean-relative modification is at most 1%. The selected strength is absorbed into both residual heads before export, so the saved model reproduces the chosen correction. Strength zero is the explicit identity control. If this wins, the result is a failed removal experiment. Alpha/beta clean-preservation measurements are reported after validation selection and can invalidate its development guard; test quality does not trigger parameter reselection.

Freeze the selected weights before inspecting the eight test records or running OSF. Save window metrics and record averages, and bootstrap records with 2,000 resamples for descriptive one-sided bounds. Exclude the two previously inspected smoke records from those bounds. These six records cannot establish participant-independent or matched-legacy superiority. Full five-fold, three-seed, old-model reruns, participant-purged adaptation and streaming gates remain required.

The frozen OSF evaluation includes every audited original session. For each, score the first genuinely annotated post-calibration 1,024-sample interval for each available rest/horizontal/vertical/blink condition. Report missing conditions explicitly. Compare region-agnostic routing with the fixed named-region prior without tuning from OSF. This is balanced condition coverage per session, not evaluation of every time sample or paired-clean accuracy. Full-session and adapted evaluations remain separate requirements.

Artifacts include the complete grid/history, last checkpoint per configuration, selected weights/configuration, exact Git/hardware metadata, validation clean measurements, held-out metrics/bounds, gate diagnostics, all-session OSF coverage/proxies, figures, offline export and fresh-process CPU reload equality. No success flag substitutes for these measurements.
